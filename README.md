# 퇴마 생존기 — 개인정보처리방침

안드로이드 게임 **퇴마 생존기**(`com.survival.autoable`)의 개인정보처리방침을
GitHub Pages 로 게시하기 위한 저장소입니다.

- 공개 주소: <https://meansmin.github.io/toema_privacy_policy/>
- 문서: [`index.html`](index.html)

이 주소를 Google Play Console 의 **개인정보처리방침 URL** 칸에 넣습니다.

## 게시 설정

저장소 **Settings → Pages** 에서

- Source: `Deploy from a branch`
- Branch: `main` / `(root)`

로 두면 됩니다. 저장하고 1~2분 뒤부터 위 주소가 열립니다.

## 고칠 때

`index.html` 한 파일뿐입니다. 고쳐서 `main` 에 push 하면 자동으로 다시 배포됩니다.
내용을 바꾸면 문서 상단의 **최종 수정일**도 같이 고쳐 주세요.

## 라이선스

이 문서는 퇴마 생존기의 법적 고지문입니다. 자유 이용 대상이 아닙니다.
